Start every new level/ending from a known video game with cool, proven gameplay, then map our story and metaphors onto it. Never start from the metaphor and invent mechanics around it.

**Why:** Julius rejected end2 v0 ("warm warehouse") and end3 v0 ("I don't even get it") on 2026-10-16. Metaphor-first drafts produced mood pieces with thin, abstract mechanics, and end1/end2 converged on the same building-wakes-up shape.

**How to apply:** name the reference game(s) up front, describe the core loop in concrete moment-to-moment terms (controls, camera, what skill is tested), then the metaphor. Julius likes big, spectacular, skill-heavy action for the finales (shooter, race). For core mechanics he wants several versions to build as MVPs and test; best one survives.
