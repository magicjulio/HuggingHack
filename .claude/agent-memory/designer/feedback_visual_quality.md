Flat, simple vector or CSS mockups are not good enough for the game's look. Julius called the 2D scorer eye "terrible" and said most of the Ch1 kit was "too simple". The 2D UI dashboard (HUD and windows) was accepted as good enough for now.
**Why:** he wants it to look like a game worth playing, not a UI wireframe.
**How to apply:** don't push 3D or visual quality off to the engineer. Find tools that make real assets: Blender 4.3.2 is installed and scriptable headless, and a Blender MCP is an option. Show rendered previews before handing anything off. See [[reference-3d-tooling]].
