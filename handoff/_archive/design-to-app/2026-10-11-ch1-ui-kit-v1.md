# Design → App: Chapter 1 UI kit v1

**What it is.** First version of all 2D/UI assets for Chapter 1, as one CSS file plus a live gallery (`assets/ch1/index.html`). Draft until Julius approves.
**Supersedes.** Nothing. Follows `2026-10-11-start-screen-and-answers.md`.

## Contents → how to drive it
- **HUD**: `.c1-tokens` (20 segments; add `.on` per 5 tokens, `.is-low` <30, `.is-hit` on loss; floor marker at 15%), `.c1-delta--gain/--cost` popups, `.c1-quests` with `.c1-quest` / `--done` / `--thought` (thought fades itself in 5 s), `.c1-toast` for the bug achievement, `.c1-hint` + `.c1-key` for `WASD · E`.
- **Paper**: `.c1-paper` (x at top left, as in the script).
- **Depot**: `.c1-win.c1-depot`, `.c1-row` (+`--noeffect`, `--glim`, `--new`), `.c1-btn` (`--busy` with `--p` 0..1, `--done`), `.c1-row--zz` (no Install), `.c1-row--edit` (locked `.c1-zz` prefix + input + `/64`), `.c1-method` (GET → `--mkcol`, `.is-pulse`, `.is-tip` for hints).
- **Scorer eye** (Julius's big-eye idea): `.c1-eye[data-state=off|idle|green|red|dark]` with the SVG in the gallery. `dark` is a one-shot stutter (1.1 s); retrigger by clearing and resetting the attribute.
- **Ceiling lamp**: `.c1-lamp[data-state=steady|flicker][data-level=1|2|3]`. This is a 2D sketch of the look; in 3D drive light intensity with the same keyframe values (see `c1-lamp1..3`).
- **Stations 1-5**: `.c1-station` + `.c1-term`, `.c1-slot(.is-ready)`, `.c1-search/.c1-counter/.c1-logs .l(.out)`, `.c1-wires` (wires drawn live by you; mock SVG is only a picture), `.c1-legend`, `.c1-code` + `.c1-bug--slow|fast|heisen|dead`, `.c1-aim`, `.c1-bolt`, `.c1-plaque` ("output → no consumer").
- **Sprites**: `assets/ch1/sprites/*.svg`.
- **Sounds**: only synthesised sketches in `sfx.js` so far.
