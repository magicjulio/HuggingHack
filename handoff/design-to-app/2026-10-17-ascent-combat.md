# ASCENT combat redesign v1: designed, staged, not yet wired

**What it is:** the combat area's handoff from the 2026-10-17 team run (brief: `2026-10-17-ascent-team-brief.md`). The run was stopped early for Julius's usage budget, so this is a **partial delivery**.
**What changed since the last handoff:** the redesign is written up in `prototypes/end2-ascent/DESIGN.md` → "Combat redesign v1 (proposal)". Six new modules are staged in `prototypes/end2-ascent/`. **None of them is imported yet.** `actors.js`, `main.js` and `smoke.mjs` are unchanged by combat, so the game still plays the old loop.
**What the receiver must do:** the next combat session (engineer or a combat agent) works through the to-do below.
**Open questions:** see "For Julius".

## Staged files (new, owner: combat; nothing imports them yet)
| File | What it holds |
|---|---|
| `enemies.js` | `BEHAVIOUR[kind](e, c)` for gunner (holds a cover post, ducks, pops up to fire, relocates when flanked), shield (advance, firing window, close-range bash with knock-back), **hugger** (rusher: weave in, red floor ring, lunge over low cover, recover), **warden** (emplacement: charge, then a sweeping beam that cover stops, then a vent that opens the armour), **maintainer** (keeps away from you, heals the most damaged defender through a tether). Also `interrupt(e, api)`, which defines what a stagger cancels. |
| `enemies-extra.js` | First-pass models `buildHugger`, `buildWarden`, `buildMaintainer(brand)`. Each uses the official logo on its face, a gunmetal hull and hazard stripes, and has the same interface as models.js (`{ root, update(dt, s), setHealth(v), dispose() }`). Not yet seen in a browser. |
| `encounter.js` | Beat director. Beats are `clear`, `push` or `hold` (a zone meter that pauses while you are outside it, plus trickle reinforcements). Beats are data in `T.encounter.floors[n]`. |
| `projectiles.js` | Enemy bolt logic only. The look comes from `looks.bolt(kind)`. |
| `looks.js` | Placeholder looks behind a swappable interface: `bolt`, `beam` (warden, warden-aim, tether, beacon), `ring` (lunge, spawn, beacon, shock, hold), `impact`, `number` (damage numbers), `update`, `clear`. The characters area's `fx.js` can replace any entry. |
| `actors.next.js` | The full `actors.js` replacement. It uses all of the above and adds per-kind stats, crits (rear ×1.5, Warden core ×2.5), Warden armour, drop-in spawns from the ceiling, taunt-weighted targeting, the squad beacon, slam, stagger and shockwave, squad orders (focus or move), and squad flanking of shields and wardens. |
